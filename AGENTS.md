# AGENTS.md

Инструкции для AI-агентов (Codex, Claude Code, Cursor, Gemini CLI и др.), работающих с репозиторием
«Библия QA». Формат — [agents.md](https://agents.md). Людям — [`CONTRIBUTING.md`](CONTRIBUTING.md).

## О проекте

«Библия QA» — русскоязычная база знаний по тестированию ПО: ~235 страниц Markdown, опубликованных
как книга GitBook: <https://vladislaveremeev.gitbook.io/qa_bible/>. Автор и владелец — Владислав Еремеев.
Лицензия — GPL-3.0. Кода приложения нет: «исходники» — это статьи.

* Публикация — GitBook Git Sync из ветки `master`. Сборки и CI нет.
* `SUMMARY.md` — оглавление сайта. **Страница, которой нет в `SUMMARY.md`, не публикуется.**
* Разделы — каталоги с транслит-именами (`obshee/`, `test-dizain/`, `mobilnoe-testirovanie/android/` …),
  у каждого есть `README.md` — титульная страница раздела.
* Картинки — `.gitbook/assets/`, подключаются относительным путём (`../.gitbook/assets/имя.png`).
* `docs/` и `tools/` — служебные, в книгу не входят.

## Команды

Нужен только Python 3.8+ (стандартная библиотека), ничего устанавливать не надо. Запуск из корня репозитория.

```bash
python3 tools/check.py                      # обязательная проверка перед коммитом: целостность + стиль изменённых страниц
python3 tools/check.py --links              # то же + внешние ссылки изменённых страниц (нужна сеть)
python3 tools/integrity.py                  # SUMMARY ↔ файлы, внутренние ссылки, якоря, картинки
python3 tools/style_lint.py --page <файл>   # нарушения гайдлайна на странице (с номерами строк)
python3 tools/style_lint.py                 # сводка по всей книге; --rule S-03, --worst 20
python3 tools/freshness.py                  # просроченные по актуальности страницы; --markers, --page <файл>
python3 tools/links.py --page <файл>        # проверка внешних ссылок страницы; без аргументов — вся книга (долго)
```

`check.py` должен завершаться «ОК». Существующий долг не мешает: известные ошибки целостности лежат в
`tools/integrity-known.json`, текущие нарушения стиля — в `tools/style-baseline.json`; падает только
ухудшение. Перерабатываемая страница должна стать полностью чистой (`style_lint.py --page` → `OK`).

## Правила работы

* **Не переименовывать, не перемещать и не удалять существующие страницы.** Имя файла = URL на сайте.
* **Новая страница** — файл по шаблону из `docs/contributing/templates/`, строка в `SUMMARY.md`,
  ссылка из `README.md` раздела.
* **Оформление и содержание — разными коммитами.** Коммит только с форматированием начинается с
  `Оформление:` (по нему `freshness.py` понимает, что содержание не проверялось); актуализация —
  `Актуализация:`. Остальные коммиты — по-русски, в повелительном наклонении: «Добавить …», «Исправить …».
* **Мелкие PR**: один раздел или до ~10 страниц, чтобы владелец мог их отревьюить.
* **Не менять смысл** при переоформлении. Определения ISTQB — цитаты, их не перефразировать.
* **Не выдумывать факты, версии и ссылки.** Каждое новое утверждение — с источником в `## Источники`.
  Если источник не найден — не добавлять утверждение.
* Не трогать разметку GitBook (`{% hint %}`, `<figure>`, `\_` в ссылках), если задача не в этом.
* Не делать массовых автозамен по всей книге без просмотра дифа каждой страницы.
* После исправления долга обновить базовые линии: `python3 tools/style_lint.py --write-baseline`,
  `python3 tools/integrity.py --write-known` — и закоммитить их вместе с исправлением.
* После проверки актуальности страницы — строка в `docs/contributing/reviewed.tsv`.

## Типовые задачи

**Привести страницу к гайдлайну:** `style_lint.py --page <файл>` → исправить по `style-guide.md` →
повторять до `OK` → `check.py` → коммит `Оформление: <страница>`.

**Актуализировать страницу:** `freshness.py --page <файл>` и `links.py --page <файл>` → сверить факты с
первоисточниками по `freshness.md` → коммит `Актуализация: <страница>` → строка в `reviewed.tsv`.

**Добавить ресурс в подборку ссылок** (`poleznye-ssylki/…`): ресурс живой, не дубль
(`grep -rn '<домен>' --include=*.md .`), без реферальных меток, в подходящей группе, в формате
`* [Название](url) — что это, язык, бесплатно/платно`.

**Проверить всю книгу:** `integrity.py`, `style_lint.py`, `freshness.py`, `links.py` (последний — долго,
результат зависит от сети; см. `integrity.md`).
