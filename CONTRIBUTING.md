# Как внести вклад

Спасибо, что помогаете «Библии QA»! Проект открыт для правок: исправления опечаток, актуализация
устаревших данных, новые статьи и ресурсы.

## Порядок

1. Сделайте форк и ветку от `master`.
2. Внесите правки, придерживаясь правил:
   * [Гайдлайн оформления статей](docs/contributing/style-guide.md) и [шаблоны страниц](docs/contributing/templates/)
   * [Правила актуализации](docs/contributing/freshness.md)
   * [Вычитка: орфография и термины](docs/contributing/proofreading.md)
   * [Целостность книги и ссылки](docs/contributing/integrity.md)
3. Проверьте изменения (нужен только Python 3.8+):

   ```bash
   python3 tools/check.py
   ```

4. Откройте pull request и заполните чек-лист из шаблона.

## Главное

* Новая страница должна быть добавлена в `SUMMARY.md` — иначе она не появится на сайте.
* Не переименовывайте существующие файлы: имя файла — это адрес страницы на сайте.
* Оформление и изменения по содержанию — отдельными коммитами; небольшие PR проще принять.
* Каждое новое утверждение — со ссылкой на источник.

Инструкции для AI-агентов — в [`AGENTS.md`](AGENTS.md).
