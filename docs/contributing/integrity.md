# Целостность книги и ссылки

Книга публикуется в GitBook через Git Sync из ветки `master` репозитория VladislavEremeev/QA_bible.
Оглавление сайта строится **только** из `SUMMARY.md`: страница, которой там нет, не публикуется.

## Проверки целостности

`python3 tools/integrity.py` — код выхода 1 при новых ошибках.

| ID | Уровень | Что проверяется | Как исправлять |
|---|---|---|---|
| I-01 | ERROR | Запись в `SUMMARY.md` ведёт на несуществующий файл | Исправить путь или вернуть файл |
| I-02 | ERROR | Страница не внесена в `SUMMARY.md` | Добавить строку в нужное место оглавления (вложенность — 2 пробела) |
| I-03 | ERROR | Страница в `SUMMARY.md` дважды | Оставить одну запись |
| I-04 | ERROR | Битая внутренняя ссылка | Относительный путь от текущего файла, с `.md` |
| I-05 | ERROR | Ссылка на несуществующую картинку | Вернуть файл в `.gitbook/assets/` или исправить имя |
| I-06 | WARN | Картинка в `.gitbook/assets/` нигде не используется | Удалить, если точно не нужна |
| I-07 | WARN | Нет H1 или почти пустая страница | Дописать или объединить с соседней |
| I-08 | WARN | У каталога раздела нет `README.md` | Создать по шаблону `templates/section-readme.md` |
| I-09 | WARN | Одинаковые H1 у разных страниц | Уточнить заголовки |
| I-10 | WARN | Ссылка на несуществующий якорь `#…` | Обновить якорь (GitBook транслитерирует заголовок) |

**Известные ошибки.** Долг, существовавший до введения проверок, перечислен в
`tools/integrity-known.json` и помечается `KNOWN` — на код выхода он не влияет. После исправления
известной ошибки обновите список: `python3 tools/integrity.py --write-known`. Добавлять новые ошибки в
этот список, чтобы «пройти проверку», нельзя.

## Структурные изменения

* **Не переименовывать и не перемещать существующие файлы.** Слаг файла — это URL страницы на сайте;
  на страницы ссылаются извне. Если перенос неизбежен — согласовать с владельцем репозитория и
  обновить все внутренние ссылки (`grep -rn 'старое-имя' --include=*.md .`).
* Новая страница: файл в каталоге раздела + строка в `SUMMARY.md` + ссылка из README раздела.
* Новая картинка: `.gitbook/assets/<осмысленное-имя>.png`, ссылка относительным путём.
* Не редактировать служебную разметку GitBook (`{% hint %}`, `<figure>`, `\_` в ссылках) без необходимости.

## Внешние ссылки

`python3 tools/links.py` — вся книга (~3000 ссылок, долго), `--page <файл>`, `--changed`, `--domain <домен>`.
Результаты кэшируются в `.cache/links.json` на 7 дней.

| Класс | Значение | Действие |
|---|---|---|
| DEAD | 404/410 или домен не существует | Найти новый адрес материала; иначе — архивная копия `https://web.archive.org/web/2024*/<url>`; иначе удалить пункт |
| MOVED | Редирект на другой домен или на главную | Если материал на месте — заменить URL конечным адресом; если редирект на главную — как DEAD |
| BLOCKED | 401/403/429 — сайт отсекает ботов | Проверить вручную в браузере; рабочие — оставить |
| ERROR | Таймаут, TLS, 5xx | Перепроверить позже; при повторе — как DEAD |

* Домены, которые всегда блокируют автоматическую проверку, перечислены в `tools/links-skip.txt` —
  их ссылки проверяются только вручную.
* Результат проверки зависит от сети: часть российских сайтов недоступна из-за рубежа и наоборот.
  Перед тем как удалять ссылку как мёртвую, проверьте её из другой сети или через архив.
* Ссылки на Telegram-каналы и telegra.ph по возможности заменять первоисточником.
* Новая ссылка должна вести на конкретный материал (не на главную), без реферальных параметров
  и UTM-меток.
